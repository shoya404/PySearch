# PySearch

PySearch is a terminal-based text search engine built with Python.

## Current Features

- Recursively scans a directory
- Reads `.txt` files
- Searches files for a keyword
- Displays matching files

## Current Status

Day 1: Basic file search implemented.

## Planned Features

- Tokenization
- Inverted index
- Multi-word search
- Search result ranking
- Top-K results using a heap
- CLI arguments
- Testing
- Benchmarking
